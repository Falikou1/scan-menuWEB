# Menu Scan – Site Vitrine Professionnel

Site vitrine moderne, élégant, responsive et ultra-performant pour **Menu Scan**, le service qui permet aux restaurants de digitaliser leurs menus physiques et de les rendre accessibles instantanément sur smartphone via QR code.

---

## 🌟 Fonctionnalités du site

- **Design minimaliste haut de gamme** : Inspiré des meilleurs standards du design web contemporain, avec une gestion soignée des espaces blancs, une typographie élégante (Outfit & Inter) et des micro-animations fluides.
- **Showcase smartphone interactif** : Défilement horizontal continu des menus et spécialités de restaurants, traversant l'écran du smartphone avec pauses automatiques et boucle fluide.
- **Section Chiffres clés** : 4 cartes d'indicateurs de performance avec effets interactifs au survol.
- **Section Restaurants partenaires** : Mise en valeur d'établissements partenaires (Saveurs d'Afrique, Urban Burger Co., et emplacement pour nouveaux partenaires).
- **Processus en 3 étapes** : Présentation claire et didactique de la solution (« Comment ça marche ? »).
- **Section Avantages** : 5 atouts majeurs de la digitalisation de menus.
- **Call-to-Action & Contact** : Boutons d'action rapides vers la digitalisation et contact direct via WhatsApp et Email.
- **100% Responsive** : Adaptation sur mesure pour smartphones, tablettes et grands écrans.
- **Accessibilité** : Respect des préférences d'animation réduites (`prefers-reduced-motion`).

## 💻 Installation et utilisation locale

1. **Cloner le dépôt** :
   ```bash
   git clone https://github.com/Falikou1/scan-menuWEB.git
   ```

2. **Lancer un serveur local** (au choix) :
   - Via un serveur PHP :
     ```bash
     php -S localhost:8000
     ```
   - Ou placer le dossier dans votre serveur local XAMPP (`htdocs/interMANUscan`) et accéder à `http://localhost/interMANUscan/`.
